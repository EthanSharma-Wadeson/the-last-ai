# Project Context

## Project identity

**Name:** The Last AI

**Type:** Artificial cognition / computational neuroscience-inspired simulation / machine learning research project

**Primary goal:** Study how a learning agent maintains internal representations of a changing social world, particularly when previously observed entities disappear.

## Core hypothesis

A sufficiently capable learning system can develop persistent internal representations of entities and environments from repeated interaction.

When an entity disappears, the representation of that entity may persist for some period and influence future behaviour.

This project tests that claim computationally without assuming that the agent is conscious or experiences human emotions.

## Important terminology

Use:

- "agent" rather than "person"
- "internal representation" rather than "memory of a person" in technical writing
- "behavioural response" rather than "grief"
- "disappearance" or "removal" rather than "death" in technical documentation
- "social relationship" for learned interaction patterns

Human emotional language can be used as an analogy in informal discussion, but experimental conclusions must remain computationally grounded.

## System layers

### Layer 1 — World

The physical and social environment.

### Layer 2 — Perception

Transforms world state into observations available to each agent.

### Layer 3 — Memory

Stores and retrieves information from previous observations.

### Layer 4 — Internal World Model

Maintains predictions or latent representations of relevant world states.

### Layer 5 — Motivation

Defines computational drives such as energy maintenance, exploration, safety, and social interaction.

### Layer 6 — Decision Making

Chooses actions using observations, memory, predictions, and motivation.

### Layer 7 — Learning

Updates parameters or representations from experience.

### Layer 8 — Measurement

Records behaviour and internal-state statistics for later analysis.

## Minimal viable agent

The first agent should have:

- position
- velocity
- energy
- perception radius
- observations
- short-term memory
- long-term memory
- simple learned values/preferences
- action selection
- learning

The first agent does not need language, consciousness, a large neural network, or complex emotions.

## Long-term ambition

The project may eventually investigate:

- persistent social representations
- memory consolidation
- forgetting
- prediction of absent entities
- adaptation after environmental change
- multi-agent learning
- emergent social structure
- world-model formation
- artificial developmental trajectories

## Non-goals

The project should not initially attempt to:

- prove machine consciousness
- reproduce human grief
- deliberately create suffering
- claim that behavioural similarity proves subjective experience
- build an unrestricted self-modifying autonomous system
