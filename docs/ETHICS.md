# Ethics

## Purpose

This project explores artificial cognition and uses emotionally suggestive scenarios such as disappearance and loss.

The project must distinguish between:

1. computational behaviour that resembles an emotional response
2. actual subjective experience

The second cannot be inferred simply from the first.

## Core principle

Do not intentionally design experiments around causing suffering.

The research objective is to study:

- memory
- prediction
- representation
- adaptation
- social learning
- forgetting

rather than to manufacture distress.

## Safe experimental design

Experiments should be:

- reversible
- simulated
- observable
- bounded
- reproducible

Agent removal should be implemented as a reversible simulator event.

## Avoid anthropomorphic conclusions

The project should not claim:

> "The agent felt grief."

unless there is an extraordinary scientific basis for such a claim.

Prefer:

> "The agent displayed a persistent behavioural change following the disappearance of a frequently observed agent."

## Consciousness

The project does not assume that the agents are conscious.

If increasingly complex architectures produce unexpected behaviour, this should be treated as a research question requiring further investigation, not automatically interpreted as subjective experience.

## Experimental safeguards

Recommended safeguards:

- no real-world autonomous control
- no unrestricted self-modification
- no persistent operation without researcher oversight
- no optimisation objective based on suffering
- complete state reset capability
- experiment logging

## Scientific integrity

The emotional framing of the project should never replace measurement.

A result is valuable because it is:

- measurable
- reproducible
- falsifiable
- interpretable

not merely because it appears emotionally compelling.
