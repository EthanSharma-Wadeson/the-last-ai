# Research Questions

## Primary question

How does an artificial agent's internal model of its social world change when previously observed agents disappear?

## Secondary questions

### Memory

1. How long does an agent retain information about a disappeared agent?
2. Which memories survive longest?
3. Does repeated interaction produce stronger representations?
4. Does an agent prioritise socially significant information?

### Prediction

5. Does an agent continue predicting observations from an absent entity?
6. How quickly does prediction uncertainty increase after disappearance?
7. Does the agent update its world model after repeated evidence that the entity is absent?

### Behaviour

8. Does disappearance alter exploration?
9. Does the agent revisit locations associated with the missing entity?
10. Does it seek replacement social interactions?
11. Does behaviour eventually return toward a pre-disappearance baseline?

### Social learning

12. Does interaction frequency affect representation strength?
13. Do cooperative relationships produce different learned representations from neutral relationships?
14. Can an agent distinguish between a frequently observed entity and an unfamiliar entity?

### Population dynamics

15. What happens when removals occur gradually versus suddenly?
16. Does the final surviving agent retain information about the broader population?
17. Does the complexity of the social network affect persistence of representations?

## Experimental principle

A result should be stated as an observable computational effect.

Good:

> "The agent's location-selection policy remained biased toward locations previously associated with Agent 7 for 4,000 simulation steps."

Avoid:

> "The agent was grieving Agent 7."

The second statement makes a claim about subjective experience that the experiment cannot establish.
